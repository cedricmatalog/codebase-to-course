A real gap you could close

The evaluation guide asks for results across model tiers, but no results are recorded anywhere in the repository.

Undocumented: evaluations/README.md:25–26 · at d8401cc

1
Run one evaluation

Pick a scenario in evaluations/, run it against a real repository, and grade it against its expected_behavior list.

2
Record what happened

Add a results file next to the scenarios noting the model, the date, and every expectation that failed.

3
Validate

Run npm test. The suite already checks that evaluation files are well formed.

Risks and unknowns: grading is human judgement, so a recorded pass is weaker evidence than a passing test. No maintainer has approved this work; it is a recommendation drawn from the repository’s own release checklist, not an assigned task.
