Run it and see a change

One command

There is no server to start and no application to open. The whole project is validated by a single command.

npm ciInstall maintainer tooling (Playwright only)
npx playwright install chromiumBrowser binary, not installed by npm ci
npm testEverything: syntax, builder, browser, evaluations shape

The test script runs static syntax checks first, then hands off to the end-to-end validation flow.

    "test": "npm run check:static && node scripts/test.mjs"

Check every script parses before running any of them.

Then run the real validation flow.

Where your change shows up

There is no watch mode and no build step for the skill itself. Nothing compiles, so an edit to SKILL.md or a reference file appears the next time something reads it — there is no stale bundle to catch you out.

Two different outputs

Test results appear in your terminal. Course output is a file: the builder writes index.html and you open it in a browser. If you edit a module and the page looks unchanged, you did not re-run the builder — the browser is showing the last assembled file.
